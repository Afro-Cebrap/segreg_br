# Contributing to territorios_negros

Thank you for considering contributing to this research project!

## How to contribute

1.  **Report bugs**: Use the GitHub issues tracker.
2.  **Suggest enhancements**: Open an issue to discuss.
3.  **Code contributions**:
    - Fork the repository.
    - Create a new branch for your feature or fix.
    - Ensure you use `renv` to maintain dependencies.
    - Submit a pull request.

## Project Standards

- Follow the directory structure:
    - `R/` for functions.
    - `analysis/` for numbered analysis scripts.
    - `data/` and `outputs/` are ignored by Git.

## Code of Conduct

Please be respectful and professional in all interactions.
